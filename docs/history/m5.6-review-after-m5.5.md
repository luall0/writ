## The user's first runs

Each failure was an assumption the container couldn't run, fixed with the test that showed
it (`d436fe7`, `b591eb8`, `ed33e7c`, `483f436`, `ad3a332`):

- `writ ls` cut the repos and the lease amended off every row (the fixed columns took 73 of
  78): the repos now have a row of their own; the state column padded (`State`'s `Display`
  doesn't pad).
- The trusted display cut values inside a word (a team id read as two): rows now break
  between words. The summary's limits row (80 columns), the template name beside the expiry
  or the state (up to 106), `writ sign`'s prompt naming the key's path (97), and `writ
  prove-key`'s rows naming the key or holding the remote's message: each on rows of its own,
  within 78 columns, the hostile display tests at the largest values.
- A pins file must be a regular file (`/dev/null` is anyone's to write); the harness writes
  its pins `0600` whatever the umask.
- Tests: git's `union` puts a blank line before what it appends (as `git notes append`);
  russh's client reports the server's disconnect at the seventh authentication attempt as a
  failure with no method left; a commit is signed before its template is lowered (signing
  refuses a lease that no longer fits); a terminal ends rows with `\r\n`.
